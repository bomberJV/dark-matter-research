Make a prediction.

I calculated how many events two proposed dark matter particles would produce in the same detector exposure. Both give roughly one. One particle must spend energy to become heavier in the collision. The other releases energy as it becomes lighter. Which count would rise more if faster particles could reach the detector?

04 / Look beyond the candidate

An explanation
predicts more.

A model that can produce this recoil also makes predictions elsewhere. The higher-energy region gives us another place to check.

__SIDEBANDS__

The weight of zero.

LZ reported zero science events in its higher-energy control region. It defined that region using the two light signals. The audit approximates it as 350–590 keV. If a model can produce the candidate, how often would this region still be empty?

LZ observation and supplementary Table S6 ↗

__ZEROS__

The figures give the expected number of empty regions per 1,000 hypothetical repeats, rounded to the nearest whole repeat. Each strip shows that fraction. The reference uses 544 km/s, one expected search event for each model, full acceptance and zero background. Acceptance is the fraction of higher-energy events the detector would retain. Its value in this region is unpublished.

How the calculation works

With the published strengths, the audit gives the search and higher-energy counts shown above. Scaling a model to one search event divides both counts by its expected search count. Multiplying the higher-energy count by acceptance gives an expected mean λ. Under Poisson counting the chance of zero is exp(−λ). This is a probability conditional on the model and settings. The probability that a model explains the candidate is a different question.

This check has a limit. The sideband acceptance is unpublished and assumed to be one. These are predictions to compare with measured high-energy events and the detector response. This export alone cannot declare a winner.

What this investigation demonstrates

Same evidence.
Different expectations.

A higgsino needs kinetic energy to enter a heavier state. At 544 km/s very few particles can pay that cost. Raising the cutoff by about 10% allows many more collisions to clear the threshold. The other model releases energy, so slower particles already contribute.

The observation has not moved. The experiment has not recorded more events. The result exposes sensitivity to an assumption; it does not establish either explanation.

Where the numbers diverge.

A model that can produce this recoil should also predict how often larger recoils occur. Dent and Newstead reported that ratio for two other particle models. I ran the comparison independently. Each number below is the predicted number of higher-energy events for every event in the search window.

One missing input

The first pair is close. In the second, the paper expects 19 higher-energy events for every one in the search window. My calculation expects one higher-energy event for roughly every 25 in the search window. How much energy the particle releases affects which window a recoil lands in. I used a mass difference of −1,000 keV. The paper leaves that value unspecified at its best fit, so the reason for the discrepancy is still open.

Inspect the two runs

The same routine used a constant 23 keV energy resolution, a laboratory speed of 250 km/s and a higher-energy band of 350–680 keV. The 1,000 GeV case used a +350 keV splitting. The 42 GeV case used −1,000 keV. Both columns are model predictions.
